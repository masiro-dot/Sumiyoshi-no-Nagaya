住吉の長屋 — 単体HTML版

使い方
1. ZIPを解凍します。
2. index.htmlをダブルクリックし、EdgeやChromeなどのWebGL2対応ブラウザで開きます。

HTML内にThree.js、操作コード、材質、CSSを同梱しています。Node.js、ローカルサーバー、インターネット接続は不要です。モデルは現在の修正版と同じです。

操作
外観・断面・歩行・立面の切替。歩行はWASD/矢印、ドラッグで視線、Eで扉。食堂・水回りなどの視点ボタンがあります。

GitHub Pages
解凍した中身をリポジトリ直下へアップロードし、Settings → Pagesで公開元のブランチと/(root)を指定してください。ビルド作業は不要です。

著作権
建築設計は安藤忠雄建築研究所に帰属します。このモデルは非公式の建築スタディです。Three.jsのライセンスはHTML内とLICENSE-three.txtに収録。

検証
単体HTMLをHTTP経由でブラウザ表示し、3D描画と主要な操作を検証。実行時の外部JS/CSS読み込みがないことを確認。検証用ブラウザがfile://を許可しないため、ダブルクリックそのものの実機検証は行えていません。
